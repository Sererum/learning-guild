# Фиксированные территории Тейвата

`anchors.json` содержит отредактированные вручную опорные точки восьми регионов и 96 участков (12 для каждого региона). Это общая география приложения, без личных программ и прогресса. Координаты выражены в процентах исходного атласа из `public/teyvat-atlas.js`.

Каждый `patches[index]` закреплён за физическим порталом `<region>-01` … `<region>-12`. Название места и исходная точка официальной карты находятся в `ATLAS_REGIONS[region].portals[index]`. Задачи и уроки не задают форму границы: они только выбирают уже подготовленный участок по своему стабильному `slotId`.

`tools/build-teyvat-territories.mjs` — инструмент подготовки графики. Он один раз переводит опорные точки в плавные кубические кривые Безье и записывает готовые литералы в `public/teyvat-territories.js`. Он не запускается при открытии карты или прохождении урока. В браузере запрещены новые круговые, шумовые, случайные, Voronoi или зависящие от расстояния зоны открытия.

Готовые кривые имеют непрерывное направление в местах стыка. Небольшое растушёвывание края (1,6 пикселя исходного атласа) убирает резкий срез без широких облаков. Каждый участок обрезается полным контуром собственного региона и не раскрывает соседей.

Нулевой прогресс не выбирает ни одного участка. Доступный или просмотренный урок, подготовленные материалы, дэйлики и необязательные разборы не раскрывают географию. Завершение основного урока раскрывает только его участок. Когда завершены все обязательные этапы блока, включая предусмотренный итоговый экзамен, выбирается полный контур региона: неиспользованные порталы короткого блока не оставляют скрытые земли. Состояние выводится из прогресса своего курса и выбранного прохода, без дополнительного игрового зачёта.

После изменения опорных точек пересобери статические кривые, проверь попадание всех 96 порталов в свои участки и региональные контуры через `tests/fixed-territories-browser-check.mjs`, затем просмотри скриншоты начального, частично открытого и полностью открытого региона. Не заменяй ручную редактуру увеличением радиусов вокруг точек.
