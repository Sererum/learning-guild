# Публичное приложение и локальные данные

**На GitHub находятся только универсальное приложение, общие правила, схемы, нейтральные шаблоны и синтетические тесты. Любой конкретный курс — включая его программу и готовые уроки — хранится локально.** Это правило одинаково для Python, ML и других предметов.

| Содержимое | Где хранится | В GitHub |
| --- | --- | --- |
| Интерфейс, карта, игровой движок, API, защищённый исполнитель | `public/`, `shared/`, общие модули | Да |
| Порядок создания roadmap, педагогический стандарт, контракт | `README.md`, `references/`, `AUTHORING.md`, `LESSON_CONTRACT.md`, общие skills | Да |
| Нейтральные шаблоны и синтетические проверки | Общие шаблоны, `tests/` | Да, без фактов о настоящем ученике |
| Manifest аккаунта, программа, карта и учебные материалы | `local-courses/<id>/` | Нет |
| Решения, текущий урок, подтверждённые темы, отзывы, согласия, награды | `local-courses/<id>/profile/` | Нет |
| Персонально подготовленные продолжения и авторские проверки | `adaptive/` внутри профиля | Нет |
| Общий для выбранных курсов профиль обучения | `local-learning-profiles/<id>/preferences.json` | Нет |
| Бюджет, запросы и ответы ИИ, версии заданий | Служебные файлы профиля курса | Нет |
| Черновики, просмотренная теория и позиция чтения | Браузерное хранилище выбранного scope и `browser-state.json` | Нет |
| Машинные пути, порт, автозапуск | `local.config.json`, `local-data/`, пользовательский LaunchAgent | Нет |
| Учебный журнал, сданные notebooks и экспорты | Личная авторская папка владельца | Нет |
| Личные фотографии и узнаваемые производные иллюстрации | `assets/` внутри локального профиля | Нет |
| Авторизация, токены, ключи | Штатные хранилища владельца | Никогда не копируются в репозиторий или учебный архив |

Общий профиль связывает только предпочтения и настройки ИИ. Roadmap, материалы, отзывы, решения, прогресс и игровые ресурсы между связанными курсами не наследуются. Подробности — [local-courses.md](local-courses.md).

`.gitignore` исключает новые локальные файлы из обычного добавления, но не удаляет уже отслеживаемый файл и прежние коммиты. Перед публикацией проверяй точное дерево и историю, которая отправляется. Удаление прежнего курса из новой версии не означает очистку GitHub-истории; переписывание истории требует отдельного согласования.

## Черновики и перенос

Перед копированием аккаунта открой «Настройки → Данные и безопасность», нажми «Подготовить черновики к переносу» и дождись подтверждения. При конфликте вкладок или ошибке не закрывай страницу до сохранения. Зеркало черновиков не является зачётом и не выдаёт наград.

Останови пишущий сервер. Для переноса нужны вся папка курса и связанный профиль обучения. При переносе нескольких курсов с одним профилем сохрани общую ссылку; не создавай скрытые независимые копии настроек. Не включай активные блокировки, машинные настройки запуска и секреты. ZIP не шифрует данные: передавай архив доверенному получателю частным каналом, не через публичный release или issue.

Старый инструмент [profile-transfer](profile-transfer.md) переносит только сохранения прежнего формата. Он не заменяет перенос полной папки нового курса с его материалами и профилем обучения. Нельзя распаковывать начальный checkpoint поверх дальнейшего прогресса.

## Личные изображения

Публичный интерфейс использует общие ресурсы. Частные портреты читаются только из выбранного профиля и не должны попадать в `public/assets/`. Обработчик проверяет допустимый формат PNG, безопасное имя, ограничения размера и отсутствие ссылок. Путь из импортированного JSON не даёт права читать произвольный файл.

API возвращает относительные URL разрешённых изображений, не абсолютные пути. Частные ответы используют `Cache-Control: no-store` и `Cross-Origin-Resource-Policy: same-origin`. При переключении аккаунта изображения и остальные данные должны оставаться привязаны к исходному аккаунту запроса.

## Обновление

`git pull --ff-only` обновляет приложение и общие правила. Локальные программы и профили при этом не заменяются стартовыми данными. Не применяй автоматические `reset --hard`, `clean` или force push для устранения конфликта; сначала сохрани и выясни различия.

Публичный push не является резервной копией ученика. Существующая частная Git-история также не переносится в публичный репозиторий. Новая публикация и изменение уже опубликованных материалов выполняются по действующим правилам согласования внешних действий.
