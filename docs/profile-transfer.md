# Перенос профиля прежнего формата

ZIP профиля — личная резервная копия. Храните и передавайте его отдельно от общего Git-репозитория. Он содержит решения и отзывы ученика. Общий репозиторий обновляет только приложение. Этот ZIP содержит лишь папку сохранений: он не переносит новую локальную программу, материалы и отдельный профиль обучения. Полный аккаунт переносится по [local-courses.md](local-courses.md).

В приложении откройте «Настройки → Данные и безопасность» и нажмите «Подготовить черновики к переносу». Дождитесь подтверждения, затем остановите сервер нужного профиля. Из папки приложения выполните:

```sh
node tools/profile-transfer.mjs export --state-file /полный/путь/профиля/progress.json --output /полный/путь/profile-private.zip
```

На другом компьютере выберите **новую, ещё не существующую** папку. Её родительская папка должна существовать:

```sh
node tools/profile-transfer.mjs import --archive /полный/путь/profile-private.zip --destination /полный/путь/нового-профиля
```

Команда покажет путь к восстановленному файлу состояния и сохранённые ID курса/профиля. Для перехода на новую версию сначала перенеси этот профиль вместе с исходным каталогом курса через `tools/migrate-local-courses.mjs` по [local-courses.md](local-courses.md). Сохрани исходные ID: от них зависит принадлежность решений и черновиков. Затем настрой единый сервер без `--profile` и `--state-file` по [инструкции установки](ALICE_AGENT_SETUP.md). Исходная папка остаётся без изменений; поверх существующей папки импорт не выполняется.

Переносятся все файлы выбранной папки профиля: прогресс и награды, персонализация, настройки обучения, проверенные решения (`checks/`), ревью, история и согласия, бюджет, версии материалов и подготовленные уроки (`adaptive/`). Неизвестные поля и файлы сохраняются без преобразования.

Черновики редактора, положение страницы, выбранный раздел и отметки просмотренной теории автоматически зеркалируются из браузера в локальный `browser-state.json`. После подготовки к переносу этот файл входит в ZIP; на новом компьютере он восстанавливается в браузер выбранного профиля. При конфликте вкладок или ошибке сохранения подготовка сообщает об этом: не закрывайте страницу до устранения ошибки. Прежние отличающиеся локальные значения при восстановлении сохраняются в архивной записи браузера. Проверенные решения дополнительно находятся в `checks/`.

Компьютерные настройки запуска кода не переносятся: после импорта включён изолированный режим. Пути к Python/Codex, автозапуск и порт настраиваются отдельно на новом компьютере. Приложение ничего не устанавливает автоматически; нужен готовый Python 3.12. Блокировки, временные файлы и кэши не включаются. Символические ссылки и подозрительные имена вроде `.env` или `api-token.json` останавливают перенос целиком.

Архив проверяется по схеме, списку файлов, размерам, CRC ZIP и SHA-256. Есть ограничения: до 20 000 файлов, до 32 МиБ на файл, до 256 МиБ суммарно. Повреждённый или небезопасный архив не публикуется в папку назначения. SHA-256 защищает от повреждения данных; это не электронная подпись отправителя.
