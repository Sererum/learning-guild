# Установка универсальной Гильдии знаний

Имя файла сохранено для старых ссылок. Инструкция подходит любому ученику и предмету. Общий клон не содержит персонального курса; личные данные переносятся отдельно по [local-courses.md](local-courses.md). Общий порядок обновлений — [GITHUB_HANDOFF.md](GITHUB_HANDOFF.md).

## Перед запуском

- Нужны готовые Node.js 20+, Python 3.12 и авторизованный локальный Codex CLI. `npm install` не требуется. Недостающие программы и вход в аккаунт согласуй отдельно; не копируй чужие токены.
- Защищённый исполнитель этой сборки работает на macOS с Seatbelt. На другой ОС без подключённой изоляции сообщи о блокере; не включай `trusted-local` как обход.
- Используй постоянную папку настоящего Git-клона. Прежний сервер и его LaunchAgent должны быть остановлены перед миграцией; один профиль не открывают два пишущих процесса.
- Для прежней установки сначала сохрани черновики и полную резервную копию. Старый `deployment.json` версии 1 и LaunchAgent одного профиля не совместимы с единым запуском версии 2: убери старый автозапуск прежней версией инструмента, архивируй настройку и перенеси курс. Не заменяй прогресс начальным checkpoint.

## Проверка среды

Все команды выполняются из корня клона. На macOS перед Python загрузи `~/.zshrc` без вывода, если файл существует. Не печатай окружение целиком.

```sh
node --version
node tools/deploy.mjs doctor
```

Если нужны явные пути этого компьютера:

```sh
node tools/deploy.mjs doctor --python "/полный/путь/python3.12" --codex "/полный/путь/codex"
```

`doctor` проверяет версии, авторизацию и защищённый запуск, не отправляя запрос модели. Он не доказывает отсутствие всех возможных обходов. Выполни негативные проверки `node --test tests/execution-sandbox.test.mjs`: на поддерживаемом Mac они должны пройти без пропусков. Не отключай защиту при ошибке.

## Единый сервер, версия 2

Если старые данные уже перенесены или это первая установка:

```sh
node tools/deploy.mjs setup --port 4327
node tools/deploy.mjs smoke
node tools/deploy.mjs start
```

В `setup` добавь те же `--python` и `--codex`, если они нужны. **Не передавай `--profile` и `--state-file`: сервер обслуживает все локальные курсы.** Занятый порт замени свободным; чужой процесс не останавливай. Сервер доступен только через `127.0.0.1`.

`setup` записывает `local-data/deployment.json` версии 2 с `mode: accounts`, путями этой машины и портом. Существующую конфигурацию автоматически не перезаписывает. `smoke` работает на временных данных и порту. Открой адрес сервера; без курсов появится создание аккаунта, с курсами — выбранный аккаунт. Переключение находится внизу слева.

На реальном профиле проверь отображение перенесённых данных без запуска задач ради тестовой награды. Код, отзывы и запросы ИИ проверяй на отдельном синтетическом курсе. Реальный запрос модели расходует лимит; предварительно согласуй такую проверку. Наличие авторизации не гарантирует доступность модели или квоты.

## Автозапуск macOS

Автозапуск в пользовательском сеансе выполняй, если он входит в запрос владельца. Сначала останови ручной сервер и просмотри точный план:

```sh
node tools/deploy.mjs stop
node tools/deploy.mjs autostart --dry-run
node tools/deploy.mjs autostart
node tools/deploy.mjs status
```

Создаётся один `~/Library/LaunchAgents/local.learning-guild.plist` для всех курсов. Он запускает сервер после входа в macOS, но не включает выключенный компьютер. Не нужны `sudo`, системная служба или сетевой доступ. По возможности проверь запуск после повторного входа. При ошибке смотри журналы.

## Управление и данные

| Нужно | Команда / место |
| --- | --- |
| Адрес и состояние | `node tools/deploy.mjs status` |
| Ручной запуск | `node tools/deploy.mjs start`; терминал оставить открытым |
| Остановить | `node tools/deploy.mjs stop` |
| Удалить автозапуск | `node tools/deploy.mjs uninstall-autostart` |
| Логи | `local-data/logs/server.log`, `local-data/logs/error.log` |
| Курс, программа и материалы | `local-courses/<id>/` |
| Прогресс, решения, отзывы | `local-courses/<id>/profile/` |
| Пожелания и effort | `local-learning-profiles/<learningProfileId>/preferences.json` |
| Настройка компьютера | `local-data/deployment.json` |

Остановка выгружает LaunchAgent из текущего сеанса; файл остаётся для следующего входа. Повторное включение после `stop`: `uninstall-autostart`, затем `autostart`. Удаление службы не удаляет курсы.

Перед переносом сохрани черновики и останови запись. Переноси целиком папку курса и её профиль обучения; не ограничивайся одним `progress.json`. Машинные настройки запуска, блокировки и секреты не копируй. Внешние правки `content.json`/`program.json` требуют перезапуска сервера; изменения через интерфейс видны сразу.

После установки сообщи владельцу адрес, способ открыть урок, расположение личных данных и результат проверки переноса. Никаких автоматических push: GitHub получает только отдельно согласованные общие изменения.
