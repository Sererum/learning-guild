## Integration

All assets are in `public/assets/`. `pages/quest-art.js` maps quest actions to individual images; achievement emblems reuse the associated painted motifs (book, sun, arrow, feather, hourglass, lock, peony, tower, marker) instead of polygon medals. `journal-theme.css` contains each image within its existing slot; landscape uses cover cropping and a text readability gradient. The workbench outline uses book/feather/lock images at16px; completion and retry indicators remain functional text.
