# Локальные курсы и общий профиль обучения

Курс в интерфейсе выглядит как отдельный аккаунт. Каждый имеет название, ученика, свою программу, материалы, героя, прогресс и отзывы. Переключатель находится внизу левой панели, у персонажа. Папки аккаунтов исключены из Git; приложение обнаруживает их по manifest.

## Структура

```text
local-courses/
  my-course/
    manifest.json
    content.json
    program.json
    profile/
      profile.json
      progress.json
      browser-state.json
      checks/
      reviews/
      adaptive/
      ...
local-learning-profiles/
  my-learning-profile/
    preferences.json
```

`manifest.json` описывает аккаунт:

```json
{
  "schemaVersion": 1,
  "id": "my-course",
  "title": "Мой курс",
  "learnerName": "Ученик",
  "profileId": "default",
  "learningProfileId": "my-learning-profile"
}
```

ID курса — постоянный безопасный идентификатор, совпадающий с именем папки. Название можно менять без смены ID и потери сохранений. `profileId` сохраняет принадлежность прогресса; при миграции используется прежний ID. `learningProfileId` указывает на локальную папку настроек обучения. Не записывай абсолютные пути чужого компьютера или ссылки за пределы локального хранилища. Необязательный `avatar` должен соответствовать разрешённому общему ресурсу приложения.

`content.json` — сериализуемый объект курса с `id`, `manifest`, `engineConfig`, `tasks`, `lessons`, при необходимости `repairPoints`, `presentation` и `adaptation`. Его учебный manifest содержит `schemaVersion`, `id`, `title`, `runtime`; это описание содержания, а manifest аккаунта дополнительно задаёт профиль и имя ученика. `program.json` описывает полный маршрут: название, конечную цель, блоки, `roadmap`, узлы и планы уроков. Его `roadmap` при загрузке заменяет прежнюю копию `adaptation.roadmap` из содержания. Поля задач и уроков — в [LESSON_CONTRACT.md](../LESSON_CONTRACT.md); порядок создания согласованного маршрута — в [references/course-creation.md](../references/course-creation.md).

В `profile/` остаются все специфичные для курса факты: решения, проверки, локальные изменения программы, отзывы, история, ресурсы, черновики и персонально подготовленные материалы. Наличие урока в `content.json` не означает его прохождения.

## Создание: два независимых выбора

| Выбор | Что происходит |
| --- | --- |
| Курс с нуля | Создаётся собственный локальный аккаунт; программа и материалы готовятся под новую цель |
| Копия курса | Программа и материалы копируются как независимая основа; прогресс, решения, отзывы и ресурсы источника не переносятся |
| Новый профиль обучения | Собственные пожелания и настройки ИИ |
| Копия профиля обучения | Снимок пожеланий и настроек; дальнейшие изменения независимы |
| Общий профиль обучения | Несколько курсов используют один `learningProfileId`; подтверждённые изменения настроек видны всем |

Можно скопировать курс и создать пустой профиль. Можно создать совсем другую программу с нуля и подключить прежний общий профиль. Термин «связанный курс» не означает наследование программы или материалов.

## Что действительно общее

Общие данные ограничены сведениями «Обо мне», пожеланиями «Как мне давать задания», подтверждёнными правилами подачи, настройками ИИ/effort и сроком напоминания о пересмотре пожеланий. В общий профиль не попадают исходные отзывы, решения, диагнозы по заданиям, этапы roadmap, игровые награды, журналы запросов и бюджет использования конкретного курса.

Перед изменением общих настроек показываются затронутые курсы. Пользователь подтверждает область действия. Конкурирующая правка не должна молча затирать более свежую версию: перечитай настройки и покажи новое предложение.

Предложения ИИ и их основания принадлежат исходному курсу. Только согласованные изменения предпочтений распространяются через общий профиль. Отказ от предложения сохраняет текущие настройки и не мешает продолжить подготовку материалов. Фоновые задания остаются привязаны к исходному аккаунту после переключения; ответы и выплаты не могут попасть в другой курс.

## Перенос старого курса

1. Сохрани браузерные черновики штатной кнопкой и дождись подтверждения. Зафиксируй текущий урок, число пройденных задач, баланс и надетые предметы для сравнения.
2. Останови старый сервер и его автозапуск. Сделай частную резервную копию всей папки курса, полного профиля и локальной конфигурации; не включай хранилища авторизации и секреты.
3. Сначала посмотри план миграции. Утилита `tools/migrate-local-courses.mjs` получает `--source-course PATH`, `--state-file PATH` и `--account ID`; `--root PATH` задаёт корень приложения. Без `--apply` она показывает план, с `--apply` выполняет перенос в новый локальный аккаунт.
4. Не меняй ID задач, уроков, курса и профиля ради красивого названия. Миграция копирует исходники и полное состояние; оригиналы остаются для проверки и возврата. Если формат несовместим, преобразуй копию с явным отчётом о каждом изменённом поле.
5. Запусти новый аккаунт и сравни прогресс, черновики, предметы, отзывы и персонализацию с исходным состоянием. Проверь новый интерфейс на временном аккаунте, не начисляя учебные награды реальному ученику.
6. После проверки используй новую установку. Для возврата останови её и запусти сохранённую прежнюю установку с её профилем. Не запускай обе установки одновременно для одной папки сохранений.

Миграция локальных файлов не удаляет материалы из истории GitHub. Очистка удалённой истории, force push и публикация требуют отдельного согласования и не входят в перенос аккаунта.

## Перенос на другой компьютер

Нужна **вся папка `local-courses/<id>/` плюс соответствующая папка `local-learning-profiles/<learningProfileId>/`**. Перед копированием сохрани черновики и останови пишущий сервер. Не копируй активные блокировки, временные файлы, машинные настройки запуска и авторизацию. На новом компьютере проверь окружение и создай собственную конфигурацию/автозапуск.

Если профиль обучения общий для нескольких переносимых курсов, перенеси его один раз и сохрани ссылки всех manifest. При конфликте существующего ID на целевом компьютере нельзя молча перезаписывать данные: импортируй в отдельное хранилище и согласуй связь. Для независимой копии настроек назначь новый ID профиля и обнови только ссылки переносимых аккаунтов.

Старый `tools/profile-transfer.mjs` переносит профиль сохранений, но не является архиватором всего нового аккаунта. Не обещай восстановление локальной программы только из прежнего profile ZIP. Секреты и публичный GitHub не используются для обмена личными данными.
