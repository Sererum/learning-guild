# Редактор Python: UX-ревью 21 октября 2026

Проверено на общем техническом курсе и временном профиле. Личные работы и результаты ученика не использовались.

## Что уже понятно

- Условие и редактор находятся рядом на большом экране; на телефоне есть переход «К редактору».
- «Запустить код», «Проверить на тестах» и помощь/ревью ИИ — разные действия. Запуск показывает вывод Python; тесты сравнивают сохранённые результаты.
- Во вкладке проверенного сценария видны его входные данные, ожидаемое и фактическое значение. После изменения кода есть предупреждение о предыдущей проверке.
- Код относится к одной задаче, автоматически сохраняется, восстанавливается после перезагрузки; редактор растёт вместе с текстом.

## Найдено и исправлено

| Помеха новичку | Изменение |
| --- | --- |
| Строки, комментарии, числа и управляющие слова выглядели одинаково | Локальная лексическая подсветка Python, включая многострочные строки, экранирование и Unicode-имена; отдельные цвета для светлой и тёмной тем |
| Для каждого имени требовалось помнить точное написание | Отключаемое дополнение слов: ключевые слова, встроенные функции, распространённые методы, имена только из текущего кода и стартового кода этой задачи |
| Автоматическая вставка могла бы перехватывать обычный Enter/Tab | Автоматический список открывается без выбранного элемента; стрелки выбирают, Enter/Tab принимают выбранный вариант, Escape закрывает; Ctrl+Space открывает явный выбор |
| Маленький код на телефоне (12px) | 16px на узких экранах, 14px на больших; слой подсветки и textarea используют одинаковые метрики и переносы |
| После редактирования старый вывод продолжал называться текущим | Надпись сразу меняется на «Вывод предыдущей версии ячейки» |
| Редактор принудительно отправлял Medium | Параметр effort не переопределяется редактором; сервер выбирает настройку соответствующей роли |

Дополнение вставляет только одно имя. Оно не добавляет алгоритмы, тела функций, вызовы с аргументами или готовые решения. Никакие внешние библиотеки, CDN, установки и обращения к модели для подсказок не добавлены. Переключатель сохраняется в существующем хранилище выбранного курса/профиля.

Рабочая область остаётся textarea с одним источником текста. Декоративный слой скрыт от скринридера; в forced-colors текст становится обычным системным текстом. Список имеет listbox/options и активный вариант. Оставлены четыре пробела, удаление одного уровня отступа, многострочное выделение, Shift+Tab и нативная отмена в Chrome.

## Проверки

- `tests/editor.test.mjs`: 3 проверки лексики, сохранности исходного текста, строк/комментариев, чисел, Unicode, незакрытых строк.
- `tests/editor-browser-check.mjs`: настоящий установленный Chrome, отдельный временный профиль и случайный loopback-порт; сервер закрывается после проверки.
- Проверены автоматический и явный список, стрелки, Tab/Enter/Escape, вставка мышью, отмена дополнения, методы, изоляция имён двух задач, отсутствие подсказок в строках/комментариях, обычный Enter и четыре пробела, Backspace/Delete, выделение нескольких строк и Shift+Tab.
- Выполнены настоящая вставка из буфера и её отмена, сохранение/перезагрузка, сохранение выключенного дополнения, дополнение при отключённой сети, независимые запуск и тесты, пометка устаревшего вывода.
- Проверены ширины 1500 и 390px: совпадение ширины цветового слоя и textarea, отсутствие горизонтального переполнения страницы, расширение редактора на 80 длинных строк без внутренней вертикальной прокрутки. Скриншоты светлой/тёмной тем просмотрены визуально.
- IME: программно проверен отказ от обработки Enter во время composition. Реальный системный IME и экранные клавиатуры разных мобильных ОС не проверялись.

## Границы реализации

Это локальное дополнение слов и лексическая подсветка, а не полный Python language server. Тип объекта не выводится: список методов общий; не каждый предложенный метод подходит каждому типу. Содержимое f-строки окрашивается целиком как строка, без отдельного разбора выражений внутри `{...}`. Ошибки синтаксиса по-прежнему объясняет запуск Python. Редкие незавершённые конструкции могут окрашиваться приблизительно; текст и выполнение от подсветки не зависят.

Нативная отмена проверена в Chrome. Для движков без `execCommand('insertText')` оставлен `setRangeText`; поведение undo такого запасного пути отдельно не подтверждено. Огромные файлы и полный набор ассистивных технологий не входили в эту проверку. Учебный контент, проверяющие сценарии и правила наград не менялись.
