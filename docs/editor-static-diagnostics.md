# Проверка записи Python и Tab

В автоматическом списке дополнений Tab сразу вставляет первый вариант. Стрелки позволяют выбрать другой; Enter без явного выбора переносит строку. Если список закрыт, Tab сохраняет поведение отступа.

После короткой паузы ввода редактор локально проверяет синтаксис и явно неизвестные имена. Ошибка подчёркивается красной волнистой линией; под редактором можно раскрыть объяснение и перейти к месту ошибки. Изменение текста сразу убирает старые отметки. Запросы выполняются последовательно, ответы старой версии не применяются.

`python-diagnostics.py` использует только `compile` для синтаксической проверки и `ast` для разбора. Полученный байткод не выполняется, импорты ученика не загружаются. Исполнитель использует существующую изоляцию macOS, лимит 16000 символов, таймаут 2.5 секунды и ограничения CPU/памяти существующего bootstrap. Endpoint требует Origin и токен сессии; не пишет ответы, результаты, награды или прогресс. Если системная изоляция недоступна, диагностика показывает недоступность и не переключается в доверенный запуск.

Области функций, lambda, классов, параметров, импортов, циклов, comprehension и match учитываются. Это консервативный анализ имён, не полный Python language server: нет проверки типов, существования атрибутов, всех путей выполнения, порядка инициализации или истинности условий. При динамических пространствах имён (`exec`, `globals`, `import *`) неизвестные имена в этой области не объявляются ошибками. Аннотации не анализируются. Отсутствие подчёркивания не гарантирует успешное выполнение; отдельные запуск и тесты остаются необходимыми.

Проверки: unit/API `python-diagnostics.test.mjs`, лексика `editor.test.mjs`, реальные Chrome-сценарии `diagnostics-browser-check.mjs` и обновлённый `editor-browser-check.mjs`. Только временные профили. Проверены исходный `sa`, исправление, синтаксис, Unicode, отсутствие исполнения кода, неизменность прогресса, поздний ответ старого запроса, последовательность запросов, desktop/mobile, Tab без стрелки и обычный Enter. Независимое ревью выявило и помогло исправить scope параметров generic class Python3.12 и гонку двух проверок.
