# Ресурсы для прокачки

Примогемы используются для молитв; книги опыта, монеты и материалы — для развития персонажа и предметов. Точные выплаты задаёт локальный курс. Универсальная платформа не обещает одинаковый запас ресурсов после конкретного номера урока.

## Правила экономики курса

- У каждого необходимого материала должен быть понятный и достижимый учебный источник. Повышение уровня не должно требовать случайного выпадения предмета из молитвы.
- Показывай награду и условия её получения перед заданием. Раздел «Где взять ресурсы?» должен объяснять действующие источники выбранного курса, а не ссылаться на чужие уроки.
- Результат задачи, прохождение урока и оценка качества — разные основания выплаты. Повторная проверка той же задачи не выдаёт основную награду заново; при улучшении качества доплачивается лишь разница до лучшего принятого результата.
- Дэйлик использует ключ календарного дня. Просмотр теории, создание программы и генерация материалов не считаются выполнением задачи и не выдают валюту.
- Новые курсы и независимые копии начинают с собственными нулевыми расходуемыми ресурсами. Стартовая экипировка задаётся общими игровыми правилами. **Миграция существующего курса сохраняет реальные ресурсы и прогресс, а не обнуляет их.**
- Импорт истории, обновление приложения и перестановка маршрута не начисляют награды задним числом. Стабильные ID и записи прошлых выплат сохраняются.

## Где задаются выплаты

Настройки конкретного курса находятся в `local-courses/<id>/content.json` → `engineConfig`: `resourceRewards`, `taskRewards`, `rewardGroups`, `qualityCaps` и правила повторяемых задач. Если поле не задано, сначала проверь поведение движка и общие значения по умолчанию; не обещай награду только на основании текста задания. Общая реализация — `shared/engine-core.mjs`, базовая игровая конфигурация — `shared/game-config.mjs`.

При подготовке курса рассчитай достижимость первого улучшения каждого вида предмета и первого возвышения: нужные уровень, монеты, книги и особые материалы должны быть доступны по учебным заданиям. Проверяй также дальнейшие ступени; не опирайся на временные тестовые начисления или случайный выигрыш. Конкретный расчёт сохраняй вместе с локальным курсом.

В предварительном расчёте улучшения показываются стоимость и недостающие материалы. Расход происходит только после подтверждения. Для проверки экономики используй синтетические данные: `node --test tests/resource-economy.test.mjs`. Реальный профиль не используется для получения тестовых наград.
