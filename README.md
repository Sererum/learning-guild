# Learning Guild

Универсальное локальное приложение для обучения: карта всей программы, уроки, редактор Python, проверка задач, помощь ИИ и развитие персонажа. **GitHub содержит приложение и общий стандарт создания курсов. Программа и материалы каждого ученика находятся только на его компьютере.**

## Первый запуск

Нужны готовые Node.js 20+ и Python 3.12. Для подготовки материалов и помощи ИИ нужен авторизованный локальный Codex. npm-зависимостей нет; `npm install` не требуется. Защищённое выполнение Python в этой сборке поддерживает macOS с рабочим Seatbelt. На другой ОС без проверенного исполнителя запуск блокируется.

Из корня приложения:

```sh
npm start
```

Для постоянной установки и автозапуска используй [инструкцию агента](docs/ALICE_AGENT_SETUP.md); единая конфигурация запуска версии 2 обслуживает все локальные аккаунты. Постоянная установка на macOS завершается включением автозапуска после входа и проверкой работающего сервера. После обновления проверь службу повторно; машинные настройки создаются отдельно на каждом компьютере и не передаются через GitHub.

Открой локальный адрес, который напечатает сервер. Если курсов ещё нет, создай первый. В дальнейшем список курсов открывается нажатием на персонажа **внизу слева**.

При создании выбираются две независимые вещи:

1. **Основа курса:** с нуля или независимая копия существующей программы и материалов. Копия начинает с собственного прогресса; последующие изменения содержания между курсами не распространяются.
2. **Профиль обучения:** новый, независимая копия существующего или общий с другим курсом. Общий профиль связывает только «Обо мне», пожелания к подаче заданий, настройки ИИ/effort и напоминание о проверке пожеланий.

Создание пустого курса само по себе не означает, что учебная программа или уроки уже подготовлены. Агент читает [правила создания программы](references/course-creation.md), выясняет цель и начальный уровень, составляет полный roadmap до конечной цели и готовит первые материалы по [AUTHORING.md](AUTHORING.md). Все результаты сохраняются в выбранном локальном курсе.

## Что где лежит

| Путь | Назначение | В Git |
| --- | --- | --- |
| `public/`, `shared/`, общие серверные модули | Интерфейс, карта, редактор, игровые механики, выполнение и ИИ | Да |
| `README.md`, `AUTHORING.md`, `LESSON_CONTRACT.md`, `references/`, общие skills | Форматы, правила создания roadmap и качества материалов | Да |
| `tests/`, нейтральные шаблоны | Синтетические проверки и примеры формата | Да |
| `local-courses/<id>/manifest.json` | Имя курса, ученика, стабильные ID и ссылка на профиль обучения | Нет |
| `local-courses/<id>/content.json`, `program.json` | Материалы, задания, карта, программа и правила наград этого курса | Нет |
| `local-courses/<id>/profile/` | Решения, прогресс, предметы, отзывы, черновики и подготовленные продолжения | Нет |
| `local-learning-profiles/<id>/preferences.json` | Самостоятельный или общий профиль обучения | Нет |
| `local-data/`, `local.config.json`, прежние `profiles/` | Личные служебные данные и настройки компьютера | Нет |

Подробности — [локальные курсы и аккаунты](docs/local-courses.md), [граница данных](docs/data-boundary.md), [контракт материала](LESSON_CONTRACT.md).

## Общий профиль обучения

Python и история искусств могут использовать один профиль, оставаясь совершенно разными курсами. Изменение общих пожеланий из любого связанного курса влияет на создание будущих материалов остальных курсов. Перед сохранением интерфейс показывает, какие курсы затронуты.

Roadmap, уроки, результаты, отзывы, игровые ресурсы и история ИИ **не являются общими**. Предложение ИИ изменить профиль требует согласия ученика; сам отзыв из одного курса не становится отзывом другого. Новые пожелания не переписывают уже пройденный урок автоматически.

## Создание и поддержка программы агентом

Читай по порядку:

1. [references/course-creation.md](references/course-creation.md) — цель, начальный уровень, полный маршрут, зависимости, планы уроков и пересмотр программы.
2. [docs/local-courses.md](docs/local-courses.md) — локальные папки, manifest и границы копирования/связи.
3. [AUTHORING.md](AUTHORING.md) и [общий skill](.agents/skills/course-material/SKILL.md) — понятные объяснения и независимая проверка каждой задачи.
4. [LESSON_CONTRACT.md](LESSON_CONTRACT.md) — поля уроков, заданий, тестов и взаимодействие с приложением.

Внешние правки локальных `content.json` и `program.json` загружаются после перезапуска сервера. Правки через интерфейс действуют сразу.

Общий стандарт обновляется вместе с приложением. Личный профиль дополняет его, сохраняя требования качества и полномочий. Поддержан исполнитель `basic-python` без сторонних импортов. Курс по ML может иметь собственный roadmap, но практику с внешними библиотеками нельзя объявлять доступной до подключения проверенного исполнителя. Изменение названия курса этого ограничения не снимает.

## Перенос прежней установки

Сначала сохрани черновики через «Настройки → Данные и безопасность → Подготовить черновики к переносу», затем останови старый сервер и сделай частную резервную копию материалов и профиля. Прежний прогресс нельзя заменять стартовым checkpoint.

Миграция копирует старое содержание и профиль в локальный аккаунт, сохраняя ID задач и результаты. Старую конфигурацию развёртывания версии 1 и её автозапуск сначала останови прежними инструментами; новая версия 2 настраивается без `--profile` и `--state-file`. Точный порядок и возврат — [docs/local-courses.md](docs/local-courses.md). Старые инструкции переноса одного `profile/` не переносят саму программу: для нового формата нужны вся папка курса **и** связанный профиль обучения.

## Обновление и проверка

Перед обновлением останови сервер, сохрани частную резервную копию и проверь состояние рабочего дерева. `git pull --ff-only` обновляет приложение, общие правила и нейтральные шаблоны; локальные курсы и профили обучения в Git не входят. Конфликты и локальные изменения нельзя устранять автоматическим сбросом.

```sh
npm test
```

Тесты используют временные профили и порты. Проверка нового курса должна подтверждать уникальные ID, корректные зависимости и отсутствие смешивания его сохранений с другим курсом. Для браузерных проверок используются уже установленные Playwright/Chrome; зависимости автоматически не устанавливаются.

Рабочий сервер слушает только loopback. Автозапуск настраивается на компьютере владельца после проверки окружения; нельзя запускать два пишущих процесса для одного профиля. Личные ZIP и папки передаются частным каналом, не через публичный GitHub.

## Ежедневные поручения

На карте и в книге поручений доступен «Дэйлик дня»: короткая практика по освоенной теме. После успешной проверки забери награду отдельной кнопкой до местной полуночи. Дата, ротация, история и награды принадлежат конкретному локальному курсу. Формат банка и правила для автора — [docs/daily-quests.md](docs/daily-quests.md).
