# Learning Guild

Локальная учебная платформа: карта пути, книга поручений, интерактивная теория, редактор Python, тесты, помощь локального Codex и развитие персонажа. Интерфейс и игровые правила общие; курсы и личные профили подключаются отдельно.

Целевой способ распространения общего кода — публичный GitHub. Личный учебный маршрут, решения, отзывы, интересы и авторский контекст остаются локальными. Подтверждённая ссылка выдаётся после фактической публикации; наличие этого каталога не означает, что remote уже создан.

## Что где находится

| Путь | Содержимое |
| --- | --- |
| public/ | Общий интерфейс, карта, книга, персонаж и редактор |
| shared/ | Общий движок, профили, предметы и награды |
| server.mjs, runner.py, review.mjs | Локальный сервер, выполнение Python и помощь ИИ |
| courses/<id>/ | Обезличенные уроки, задачи, общая карта и награды |
| courses/alice-python/ | Совместимый учебный пакет базового Python; ID сохранён |
| courses/starter-python/ | Маленький технический пример; не готовый курс ML |
| profiles/<course>/<profile>/ | Личные сохранения, course-state.json, отзывы, ИИ и персонализация; вне Git |
| local-data/, local.config.json | Личные служебные данные и настройки компьютера; вне Git |
| AUTHORING.md, LESSON_CONTRACT.md | Общие правила объяснений и контракт данных |

[Точная граница публичного и локального](docs/data-boundary.md). Публичные тесты могут содержать авторские эталоны: скрытость сценариев в интерфейсе не делает открытый GitHub секретным.

## Первая установка

Нужны уже установленные Node.js 20+, Python 3.12 и для ИИ — авторизованный локальный Codex. npm-зависимостей нет: npm install не требуется. Защищённое выполнение в этой сборке поддерживает macOS с рабочим Seatbelt. На другой ОС без проверенного исполнителя запуск блокируется; автоматического перехода в доверенный режим нет.

Для продолжения обучения получить настоящий публичный клон и отдельно импортировать переданный владельцем профиль из частного ZIP. Пустой клон сам не знает, что человек уже проходил. Не заменять существующий профиль стартовым checkpoint. Порядок — [GITHUB_HANDOFF.md](docs/GITHUB_HANDOFF.md).

Из корня приложения:

    node tools/deploy.mjs doctor
    node tools/deploy.mjs setup --state-file "/полный/путь/импортированного-профиля/progress.json" --port 4327
    node tools/deploy.mjs smoke
    node tools/deploy.mjs start

У импортированного сохранения setup берёт исходный ID из profile.json. Можно явно передать --profile ID; несовпадение блокирует настройку без изменения профиля. Для нового, ранее не существующего профиля используйте setup --profile ID без --state-file. Если порт занят, выбрать другой свободный --port. Полные пути Python/Codex передать через --python и --codex; они создаются на этом компьютере и не публикуются. Автозапуск включается отдельно после согласия владельца. Инструкция — [ALICE_AGENT_SETUP.md](docs/ALICE_AGENT_SETUP.md).

Без Codex можно отдельно запустить сервер для материалов и защищённых Python-тестов через npm start; агентский deploy проверяет также готовность ИИ. Имена курса и профиля можно задать штатными --course и --profile. Нельзя запускать один профиль двумя процессами.

## Обновление

Остановить сервер, сохранить резервную копию личных папок, проверить git status --short и получить git pull --ff-only. Затем выполнить проверки на временном профиле и запустить сервер. Не перезаписывать profiles/, local-data/ и local.config.json. pull обновляет общие исходники и курс; личный профиль между компьютерами автоматически не синхронизируется. Публичный push не используется как резервная копия ученика.

Перед частным ZIP-переносом открыть «Настройки → Данные и безопасность», нажать «Подготовить черновики к переносу» и дождаться подтверждения. Непроверенный код, просмотренная теория, выбранная задача и позиция страницы сохраняются в локальный browser-state.json и входят в полный архив профиля. При конфликте вкладок или ошибке не закрывать исходную страницу до успешного сохранения.

## Курсы и материалы

Педагогическая основа игры закреплена в [AUTHORING.md](AUTHORING.md), а порядок создания материала — в [общем skill](.agents/skills/course-material/SKILL.md). Эти файлы и использующий их генератор входят в Git: после обновления приложения агент получает те же правила без ручного переноса инструкций. Основа общая для всех курсов; личные отзывы и диагностические наблюдения в неё не копируются.

[Подключение курсов](courses/README.md), [учебный стандарт](AUTHORING.md), [контракт](LESSON_CONTRACT.md). У курса свои уроки, карта, задачи, общие зависимости и награды. Локальный course-state.json задаёт подтверждённую историю, персональный текущий урок и представление пути; private adaptive/ хранит продолжения, подготовленные по личному фидбеку.

Новые материалы проверяются настоящим Python и независимо рецензируются до подключения. Проверка авторского эталона не является прохождением учеником. Ревью ИИ после тестов оценивает логику, читаемость и эффективность отдельно; помощь предлагает диагностический шаг без полного решения.

Поддержан runtime basic-python без сторонних импортов. Настоящий ML-курс потребует своего проверенного исполнителя, библиотек и данных; смена файла конфигурации не разрешает произвольные импорты.

Личные notebooks и журнал находятся вне публичного клона. Для Colab-экспорта генераторы требуют явно заданный GUILD_AUTHORING_ROOT на частную папку с notebooks/. Без неё сборка проверяется в памяти и не пишет в произвольную родительскую директорию.

## Проверки и управление

    npm test
    npm run check:course
    npm run check:course -- --course starter-python

Проверки используют временные профили и порты. Для браузерных сценариев нужны уже установленные Playwright/Chrome; путь к браузеру задаётся через GUILD_CHROME_BIN. Матрица сценариев — [QA_REPORT.md](QA_REPORT.md).

В настройках доступны «Обо мне», пожелания к задачам, ограничения подготовки уроков, общие предложения и управление личными данными. Предложенные ИИ изменения применяются только после выбора ученика. Отказ не мешает продолжить с прежними настройками. Общие предложения не редактируют автоматически исходные правила или полномочия агента.

Отправка урока запускает локальную подготовку; просмотр или один запуск тестов этого не делают. Личные результаты и generated-уроки не публикуются автоматически. Риски и ограничения — [adaptive-learning-risks.md](docs/adaptive-learning-risks.md), контроль мер — [risk-controls-acceptance.md](docs/risk-controls-acceptance.md).
