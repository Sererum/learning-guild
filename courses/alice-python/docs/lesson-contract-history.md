# Совместимость прежних контрактов

Актуальный контракт — [LESSON_CONTRACT.md](../../../LESSON_CONTRACT.md). Этот документ описывает только совместимость форматов, а не результаты или личный маршрут ученика.

- Корневые адаптеры учебных модулей сохраняют прежние импорты; редактируемый источник один — пакет курса.
- Вспомогательные activeLesson, notebookLesson и algorithmLesson могут присутствовать в старых клиентах. Новое открытие использует реестр lessons и стабильный ID материала.
- Прежние ключи браузерных черновиков мигрируются только в явно выбранный профиль. Новый профиль и другой курс не получают чужие код, отзывы и баланс.
- Прежний data/progress.json поддерживается как явно настроенный локальный путь. Новые сохранения находятся в profiles/<course>/<profile>/progress.json.
- Старые доказательства прохождения и выплаты сохраняются локально. Миграция не разрешает импортировать персональную историю из публичных исходников или выплачивать награды повторно.
- Авторские эталоны и скрытые сценарии отделены от ученического API. Открытый репозиторий может содержать тестовые эталоны: клиентская скрытость не является секретностью публичного GitHub.

Конкретные записи миграций и проверки сохранности рабочего профиля принадлежат локальному журналу владельца. Публичная граница — [data-boundary.md](../../../docs/data-boundary.md).
