# Учебный пакет базового Python

Здесь находятся общие уроки, примеры, условия, стартовый код, тесты, адресная практика и правила учебных наград. Общая платформа импортирует пакет через index.mjs. Идентификатор alice-python сохранён для совместимости; он не предоставляет биографию или результаты какого-либо пользователя.

course.json задаёт название, ID и исполнитель. world.json — регионы, координаты и маршруты. rules.json — нейтральные зависимости, награды и каталог допустимых исторических записей; наличие записи в каталоге не подтверждает её прохождение. presentation.json содержит нейтральные подписи. Личное представление пути и подтверждённые записи поступают из profiles/<course>/<profile>/course-state.json. lessons.mjs и tasks.mjs — реестры материалов и задач.

Реальные ответы, кошелёк, предметы, отзывы, интересы и черновики в пакет не входят. Личные журналы, экспорты, notebooks и подготовленные по частному фидбеку продолжения находятся вне публичных исходников. Правила — [data-boundary.md](../../docs/data-boundary.md).

## Colab-экспорт

Чистый templates/blank.ipynb позволяет проверять сборку notebook в памяти после клонирования. Для записи или сравнения с частным авторским notebook укажите GUILD_AUTHORING_ROOT на папку этого компьютера с notebooks/. Без явного пути генератор не пишет в произвольные родительские директории. Личный профиль и журналы из этой папки не копируются в публичный репозиторий.

Стабильные ID сохраняют совместимость решений и выплат. Само наличие материала, эталона или тестового успешного результата не является самостоятельным прохождением учеником. Публичный GitHub делает серверные учебные тесты и авторские проверочные решения доступными читателю; скрытость в интерфейсе не является секретностью исходников.
