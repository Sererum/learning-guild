# Подключаемые курсы

Приложение одно: карта, книга, редактор, запуск Python, помощь ИИ, персонаж, предметы и молитвы. Каждый курс подключает свои уроки, задачи, карту и правила наград.

- `alice-python/` — пакет общих учебных материалов Python. Идентификаторы задач, порядок и содержимое сохранены, чтобы прежние решения и выплаты продолжили работать.
- `starter-python/` — технический пример другого курса для проверки загрузчика и отсутствия чужого прогресса. Это **не** программа по ML.

Курс состоит из `course.json`, серверного `index.mjs` и файлов авторского содержания. `presentation.json` задаёт подписи и представление пути. В Python-пакете `world.json` содержит регионы, координаты точек и маршруты; `rules.json` — общие зависимости, группы задач и награды; подтверждённая история предоставляется локальным профилем. Маленький `rules.mjs` объединяет JSON с общими игровыми предметами. Сами данные Python-тестов находятся только в серверных модулях курса.

`loadCourse({courseId: 'alice-python'})` загружает встроенный пакет. Для внешней локальной директории используется явный `loadCourse({courseDir: '/полный/путь/к/курсу'})`. Загрузчик не обходит диски в поисках материалов. Авторский `.mjs` — доверенный выполняемый код; нельзя подключать неизвестный пакет как безопасный документ.

Загрузчик проверяет уникальность и безопасность идентификаторов, ссылки уроков/задач/карты, зависимости и циклы, величины наград и сериализуемость правил. `validateCourse(course)` позволяет проверить собранный объект отдельно. Сервер получает готовый объект курса; отдать его целиком клиенту нельзя: тесты должны пройти через общий публичный проектор.

Рабочие сохранения, черновики, отзывы, проверки решений и история разговоров не являются содержимым курса. Они хранятся отдельно от файлов, обновляемых через Git. Новый курс не должен заимствовать подтверждённые темы и выплаты другого ученика.

Для Python сейчас поддерживается `runtime: "basic-python"`: независимые задачи, учебный набор встроенных функций, без импортов внешних библиотек. Курс ML потребует отдельного проверенного исполнения с нужными зависимостями, данными и ограничениями; один файл конфигурации не включает произвольные импорты.

Правила подготовки объяснений и независимой проверки задач лежат в общем авторском стандарте проекта; профиль, выполненные работы и личный журнал ученика подаются как отдельный контекст. Они не нужны для запуска приложения.
