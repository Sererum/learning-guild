# Формат курсов

Конкретные программы и материалы хранятся локально в `local-courses/<id>/` и исключены из Git. Этот каталог больше не является местом публикации курсов учеников.

- [Создать программу от начала до конечной цели](../references/course-creation.md).
- [Локальные аккаунты, manifest, копирование и общий профиль обучения](../docs/local-courses.md).
- [Педагогический стандарт](../AUTHORING.md).
- [Поля уроков, задач и проверок](../LESSON_CONTRACT.md).

Прежний формат `course.json` + доверенный серверный `.mjs` используется только для совместимого чтения и миграции старых пакетов. Новые локальные аккаунты содержат manifest, сериализуемый `content.json`, `program.json` и собственный `profile/`. Исполняемый JavaScript из неизвестной папки не считается безопасным документом.

Технический пример формата не является готовой программой для ученика. Ни он, ни общий профиль обучения не дают зачёт чужих знаний, решений или наград.
