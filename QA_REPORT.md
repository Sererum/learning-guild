# Проверка общей платформы

Публичный отчёт описывает технические сценарии и учебные контракты. Персональные состояния, реальные балансы, ответы, отзывы и история отдельного прохождения здесь не фиксируются. Записи прежних частных проверок сохранены локально вне Git.

| Область | Проверка |
| --- | --- |
| Платформа, курсы, профили, выплаты и API | npm test |
| Контракт встроенного курса | npm run check:course |
| Другой технический курс | npm run check:course -- --course starter-python |
| Изоляция Python и запрет fallback | node --test tests/execution-sandbox.test.mjs |
| Переносимый запуск и план автозапуска | node --test tests/deploy.test.mjs |
| Дневные награды без повторных выплат | node --test tests/daily-release.test.mjs |
| Обходы учебных условий | tests/algorithm-shortcuts.test.mjs, tests/repairs.test.mjs |
| Достижимость улучшений | tests/resource-economy.test.mjs |
| Два курса и отдельные профили в браузере | tests/course-browser-check.mjs |
| Полный алгоритмический урок | tests/full-algorithms-browser-check.mjs |

Тесты используют временные профили и порты, закрывают серверы. Браузерные проверки требуют уже установленные Playwright и Chrome; зависимости автоматически не скачиваются.

Инварианты: тесты доступны без предварительного запуска кода; теория не показывает редактор задачи; ID связывают черновики, доказательства проверки и выплаты; просмотр не выдаёт награды; повтор не дублирует выплату; изменение контента требует актуальной проверки и сохраняет старые решения в локальном архиве.

ИИ проверяется отдельно: помощь без готового решения, три оценки качества после тестов, видимые состояния ошибки/ожидания и отсутствие бонуса при невалидном ответе. Контролируемые fixtures проверяют платформу, но не гарантируют поведение любой модели. Живой запрос согласуется с владельцем и выполняется на временном профиле.

Успешный технический прогон не доказывает понимание человеком и не меняет учебный статус. Правила — [AUTHORING.md](AUTHORING.md), контракт — [LESSON_CONTRACT.md](LESSON_CONTRACT.md), приватность — [data-boundary.md](docs/data-boundary.md).
