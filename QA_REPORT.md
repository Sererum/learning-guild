# Проверка общей платформы

Документ перечисляет переносимые технические проверки, а не удостоверяет последний прогон. Итог запуска фиксируется отдельно с версией приложения. Персональные состояния, реальные балансы, ответы, отзывы и история отдельного прохождения здесь не сохраняются. Прежние проверки конкретных курсов не подтверждают новую универсальную сборку.

| Область | Проверка |
| --- | --- |
| Общий набор unit/API-проверок | `npm test` |
| Формат выбранного локального курса | `npm run check:course -- --course-dir "/полный/путь/local-courses/id"` |
| Создание, копия, связь только настроек, переключение HTTP-аккаунтов, миграция | `node --test tests/local-accounts.test.mjs` |
| Границы общего профиля обучения, согласие и актуальная редакция | `node --test tests/shared-learning-profile.test.mjs` |
| Пустой курс → согласованный план → первый материал | `node --test tests/blank-course-generation.test.mjs` |
| Разные технические курсы: движок, API и представление | `node --test tests/course-engine.test.mjs tests/course-server.test.mjs tests/course-ui.test.mjs` |
| Изоляция Python и запрет тихого fallback | `node --test tests/execution-sandbox.test.mjs` |
| Единый запуск v2 и план автозапуска | `node --test tests/deploy.test.mjs` |
| Согласие на персонализацию, подготовка и независимое ревью материала | `node --test tests/personalization-consent.test.mjs tests/adaptation-service.test.mjs tests/adaptation-audit.test.mjs` |
| Черновики, зеркалирование, восстановление и маршрут урока | `node --test tests/browser-state.test.mjs tests/browser-mirror.test.mjs tests/lesson-routing.test.mjs` |
| Интерфейс адаптации на синтетическом курсе | `node tests/learning-browser-check.mjs` |
| Интерфейс настроек на синтетическом курсе | `node tests/risk-settings-browser-check.mjs` |

В чистом клоне нет встроенного курса ученика и отдельного `starter-python`; проверки используют нейтральные fixtures и временные каталоги. Команда `check:course` проверяет структуру указанного локального курса, но не ясность заданий, достижимость наград или освоение человеком. Каждая новая задача дополнительно проходит авторское и независимое ревью по [AUTHORING.md](AUTHORING.md).

Тесты используют временные профили и порты, закрывают серверы. Браузерные сценарии запускаются отдельно и требуют уже установленные Playwright и Chrome; зависимости автоматически не скачиваются. Наличие сценария не означает, что он был выполнен на этой машине. Для учебных начислений используй только тестовые данные.

Инварианты: ID связывают черновики, проверки и выплаты; просмотр не выдаёт награды; повтор не дублирует выплату; изменение содержания требует актуальной проверки и сохраняет старые решения. В общем профиле обучения находятся только подтверждённые пожелания и настройки; программа, уроки, отзывы, прогресс и ресурсы остаются раздельными. При миграции полный профиль и исходные ID сохраняются, вместо прогресса не создаётся пустое начальное состояние.

ИИ проверяется отдельно: помощь без готового решения, три оценки качества после тестов, видимые состояния ошибки/ожидания и отсутствие бонуса при невалидном ответе. Контролируемые fixtures проверяют платформу, но не гарантируют поведение любой модели. Живой запрос согласуется с владельцем и выполняется на временном курсе.

Успешный технический прогон не доказывает понимание человеком и не меняет учебный статус. Правила — [AUTHORING.md](AUTHORING.md), контракт — [LESSON_CONTRACT.md](LESSON_CONTRACT.md), приватность — [data-boundary.md](docs/data-boundary.md).
